# HabitTracker

**HabitTracker** — iOS-приложение для создания и отслеживания ежедневных привычек и единичных событий. Пользователь может создавать трекеры с названием, цветом и эмодзи, задавать расписание по дням недели и закреплять избранные привычки. Все трекеры группируются по категориям, включая отдельную секцию для закреплённых. Приложение сохраняет выполненные привычки как записи с датой и идентификатором трекера.

## Возможности
- Создание привычек и событий с названием, цветом и эмодзи  
- Настройка расписания (дни недели)  
- Закрепление избранных трекеров  
- Группировка по категориям  
- Удаление и редактирование трекеров  
- Подсчёт выполнений и статистика  
- Сохранение данных локально через Core Data  

## Стек
- **Язык:** Swift  
- **UI:** UIKit  
- **Архитектура:** MVVM + Core Data + NSFetchedResultsController  
- **Хранение:** Core Data с кастомным ValueTransformer  
- **Анимации и интерфейс:** кастомные ячейки, цвета и эмодзи  
- **Минимальная iOS:** 15.0+
